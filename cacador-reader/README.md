# Caçador Reader — versão 0.3.0 INSTÁVEL

Protótipo experimental de leitor de telas Android em Java, com síntese de voz pt-BR, ajuste de velocidade e gestos experimentais.

## Compilação automática
O GitHub Actions compila o APK de depuração quando este projeto é enviado à branch `master`. Abra a aba **Actions**, entre no fluxo **Compilar Caçador Reader (Android)** e baixe o artefato `cacador-reader-debug-apk) quando a execução terminar com sucesso.

## Importante
Este pacote é código-fonte, não um APK testado. A compilação pode revelar erros que ainda precisam ser corrigidos. A navegação por gestos é experimental; mantenha outro leitor de telas confiável até validar o protótipo no dispositivo.
